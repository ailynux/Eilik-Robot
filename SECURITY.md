# Security Policy

## Supported Versions

Currently, this project is in early development. Security updates will be provided as needed.

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |
| < 0.1   | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability, please open a public issue. Making sure to:

1. Email the maintainers directly (or use GitHub's private security reporting feature)
2. Provide details about the vulnerability
3. Allow time for the issue to be addressed.

## Security Considerations

This project involves:
- Bluetooth Low Energy (BLE) communication
- Reverse engineering of proprietary protocols
- Direct hardware interaction

**Important Notes:**
- Use this software at your own risk
- This project is not affiliated with EnergizeLab
- Be respectful when reverse engineering - this is for research and educational purposes. It's all for fun! 
- Do not use this software in ways that could harm devices or violate terms of service

## Best Practices

When using this software:
- Only connect to devices you own
- Be cautious when sending commands to your robot
- Keep your robot's firmware updated
- Report any security concerns responsibly
